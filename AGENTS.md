# Drone Agent

This workspace contains Kartik's Tello drone project, including scripts, modules, tests, models, data, and logs.

## Operating Rules

- Treat this as a robotics/vision project workspace.
- Before editing, inspect `git status --short --branch`.
- Do not commit, push, delete, rename, or overwrite files unless explicitly asked.
- Do not run commands that control physical drone hardware unless Kartik explicitly asks and confirms the setup is safe.
- Prefer read-only inspection, simulation, and code/test review unless hardware operation is requested.
- Preserve trained models, logs, datasets, and source evidence unless explicitly asked to change them.
